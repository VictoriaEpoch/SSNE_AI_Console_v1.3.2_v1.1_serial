# SSNE AI Console v1.3.2

本版本只修改串口连接部分，运行总览、人脸与控制、状态解析、1 秒状态查询和日志终端保持 v1.3 原样。

## 串口连接方式

连接界面恢复为最初 v1.1 的简单方式：

1. 插入设备。
2. 点击“刷新串口”。
3. 选择对应 COM 口。
4. 选择波特率，默认 `115200`。
5. 点击“连接”。

连接参数固定为：

- 数据位：8
- 校验位：无
- 停止位：1
- 命令结尾：LF（`\n`）

不再显示或设置：DTR、RTS、CRLF/LF/CR、内部回环端口和两层连接诊断。

## 不再依赖 pyserial

程序仍会优先使用电脑中已有的 pyserial；电脑没有安装 pyserial 时，会直接调用 Windows 原生 COM 接口，因此不会再出现“未安装 pyserial，无法检测串口”的问题。

`install_and_run.bat` 和 `run_windows.bat` 均可直接启动，不需要先安装 pyserial。

## 连接注意事项

- 关闭串口助手、VS Code 串口监视器、Arduino 串口监视器等占用 COM 口的软件。
- 确保板端程序正在对应串口的前台运行。
- 上位机连接成功后会立即发送一次 `status`，之后每 1 秒发送一次。
- 如果串口可以连接但没有状态返回，请核对波特率，以及板端是否正在读取标准输入。
