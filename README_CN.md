# SSNE AI Console v1.3.2

本上位机已按 `ssne_ai_demo (5).zip` 中的 `UART_COMMANDS.md` 接入板端协议，覆盖串口连接、紧凑状态解析、推理模式、人脸录入、久坐告警、起夜告警、跌倒告警、人员/宠物危险区、手势模拟家居和性能测试。危险区点击一次“下发并启用”即可，软件会自动逐点发送并等待板端确认，同时在页面报告进度和失败步骤。

## 启动

推荐双击：

```text
install_and_run.bat
```

脚本会安装危险区截图所需的 Pillow，然后启动程序。也可以手动执行：

```powershell
python -m pip install -r requirements.txt
python main.py
```

## 串口连接

1. 插入设备并关闭会占用端口的串口助手。
2. 在“串口连接”页点击“刷新串口”。
3. 选择 COM 口和波特率（默认 `115200`）。
4. 点击“连接”。

通信参数为 `115200 8-N-1`，命令按参考客户端使用 `CRLF` 结尾。单条命令内容最多 24 个字符且 UTF-8 编码后最多 24 字节，不计算结尾 `CRLF`；自动命令、手动终端和底层发送队列都会在发送前拦截超限命令，不会截断。程序优先使用 pyserial；电脑没有 pyserial 时，会直接调用 Windows 原生 COM 接口。

连接成功后默认每秒发送一次 `status`；启用智能家居手势控制时，`status` 会加快到约 250ms 一次，以免短手势被 1 秒刷新间隔漏掉。启用久坐监测，或当前时间处于已启用的起夜监测时段时，每秒还会发送一次不改变周期输出开关的 `debug`，读取板端 `sv/sc` 姿态字段。

兼容两套状态格式：

- 参考包当前格式：`[SERIAL][S] f=... fs=... p=...`、`[SERIAL][D] sv=... sc=...`
- 旧版格式：`[SERIAL][STATUS] frame=... fall_status=...`

## 久坐告警

在“姿态控制 > 久坐”页：

1. 勾选“启用久坐告警”。
2. 设置阈值，默认 30 分钟。
3. 点击“应用”。

板端姿态调试字段 `sc=1` 代表 `SITTING`。上位机在检测到有人且姿态有效时连续计时；站立、躺卧或人员离开会清零，短时姿态丢失保留 5 秒缓冲。达到阈值后，顶部告警条、日志和系统提示音会同时触发。

## 起夜告警

参考板端没有独立的起夜命令，上位机使用已有姿态字段组成起夜状态机。入口位于“姿态控制 > 起夜”：

1. 设置夜间时段，默认 `22:00` 至次日 `06:00`，支持跨零点。
2. 设置躺卧确认时间，默认 30 秒。
3. 设置起身确认时间，默认 2 秒。
4. 勾选“启用起夜告警”并点击“应用”。

夜间先连续检测到 `sc=0/LYING` 才会布防；布防后连续检测到 `sc=1/SITTING` 或 `sc=2/STANDING` 才触发起夜告警。一次告警后必须再次确认躺卧，才能重新布防，因此不会因持续站立而反复报警。

## 危险区域：截屏并绘制多边形

危险区坐标必须和板端摄像头完整画面对应。使用流程：

1. 先在电脑上显示板端的完整视频画面。
2. 打开“姿态控制 > 危险区域”，点击“截取屏幕区域”。
3. 在桌面上拖动框选完整视频画面，不要只框危险区。
4. 在弹出的编辑器中，左键依次添加多边形顶点。
5. 拖动白色顶点可以调整；右键顶点删除；右键空白或 `Backspace` 撤销。
6. 点击“下发并启用”。

也可点击“导入截图”，再绘制区域。多边形至少 3 点、最多 12 点。上位机会把顶点换算为归一化坐标。用户只需点击一次按钮，软件会等待每条命令得到板端确认后，自动继续发送：

```text
zone clear
zone add <x1> <y1>
...
zone add <xn> <yn>
zone on
zone list
```

危险区坐标会四舍五入到最多两位小数并去掉末尾多余的零，例如 `zone add 0.2 0.8`。危险区域页面会同步显示当前确认点数、启用核对结果或失败步骤。

板端使用检测框底边中心（人员/宠物的落脚点）判断是否进入多边形。状态字段：

- `dz/dzn`：危险区是否开启、顶点数量
- `dzt/dzh/dza`：人员目标数、命中数、是否告警
- `pzt/pzh/pza`：宠物目标数、命中数、是否告警

本地会保存久坐、起夜设置和归一化多边形顶点；截图本身不会落盘。

## 手势模拟家居

“智能家居”页使用板端 `gc/gs` 手势类别和分数，模拟控制客厅灯、卧室灯、窗帘、空调和电视。手势控制已扩展为“轻触 + 长按”两套映射：GA～GE 仍然只依赖板端 5 个类别，但上位机可表达 10 个逻辑指令。

新增能力包括：

- 21 个可选动作：不执行、5 个设备开关、4 个灯光亮度动作、2 个空调温度动作、2 个电视音量动作、全部灯光开关，以及回家、离家、观影、阅读、睡眠场景。
- 默认长按预设：GA 打开全部灯光、GB 阅读场景、GC 观影场景、GD 睡眠场景、GE 离家场景。
- 长按进度条、防误触确认、松手释放锁定和短暂掉分缓冲。
- 手势映射、分数阈值、连续确认次数、释放时间和长按时间会随用户设置保存。
- 左侧设置区可滚动，窗口较小时也能完整配置轻触和长按动作。

详细操作见 [智能家居手势模拟控制说明](智能家居手势模拟控制说明.md)。

## 设备控制

“设备控制”页提供：

- `base / hand / face / pose / all` 推理模式
- 静态背景和姿态关键点开关
- 立即扫脸、状态与调试查询
- `reg <id> <name> <frames>` 多帧人脸录入
- 状态打印周期
- `test base|face|pose|all|each` 性能测试

“日志终端”仍支持手动发送任意命令，可发送 `help` 或 `pro` 查看板端帮助。

当前上位机实际使用的串口命令、参数约束和回包字段见 [串口命令接口文档](串口命令接口文档.md)。

## 告警说明

运行总览会统一显示：人员状态、姿态/久坐计时、起夜布防、跌倒状态、危险区状态和板端帧率。以下状态会触发告警条和提示音：

- 已确认跌倒：`fs=FL`
- 人员进入危险区：`dza=1`
- 猫或狗进入危险区：`pza=1` 或 `[SERIAL][PET_DANGER][ALERT]`
- 连续坐姿达到本地久坐阈值
- 夜间已确认躺卧后转为坐姿或站立
